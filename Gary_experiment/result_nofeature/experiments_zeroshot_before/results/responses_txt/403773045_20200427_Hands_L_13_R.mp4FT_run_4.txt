#### 1. Plotting the Data
We start by plotting the x and y coordinates of both the thumb and index finger over time (frames). This helps us visualize the tapping pattern, amplitude, and any irregularities in the movement.

```python
import pandas as pd
import matplotlib.pyplot as plt

# Read the CSV file
df = pd.read_csv('finger_tapping_data.csv')

# Plotting the coordinates for thumb and index finger
plt.figure(figsize=(12, 6))

plt.subplot(1, 2, 1)
plt.plot(df['frame'], df['X_thumb'], label='Thumb X')
plt.plot(df['frame'], df['Y_thumb'], label='Thumb Y')
plt.title('Thumb Coordinates Over Time')
plt.xlabel('Frame')
plt.ylabel('Coordinate (pixels)')
plt.legend()

plt.subplot(1, 2, 2)
plt.plot(df['frame'], df['X_index'], label='Index X')
plt.plot(df['frame'], df['Y_index'], label='Index Y')
plt.title('Index Finger Coordinates Over Time')
plt.xlabel('Frame')
plt.ylabel('Coordinate (pixels)')
plt.legend()

plt.tight_layout()
plt.show()
```

#### 3. Analyzing Tapping Characteristics
We evaluate the tapping characteristics based on the MDS-UPDRS criteria:

- **Speed**: Calculate the average time between taps to assess if there is slowing.
- **Amplitude**: Measure the distance traveled during each tap to check for decrementing amplitude.
- **Hesitations and Halts**: Identify any interruptions or pauses in the tapping pattern.

#### 4. Assigning the Score
Based on the analysis, we assign a score according to the MDS-UPDRS criteria:

| Score | Criteria |
|-------|----------|
| 0     | Normal: No problems. |
| 1     | Slight: One or two interruptions, slight slowing, amplitude decrements near the end. |
| 2     | Mild: 3–5 interruptions, mild slowing, amplitude decrements midway. |
| 3     | Moderate: More than 5 interruptions or longer arrests, moderate slowing, amplitude decrements starting early. |
| 4     | Severe: Cannot or can only barely perform the task. |
